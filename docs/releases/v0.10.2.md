# Rimlink 0.10.2

Гильдейские бои теперь доступны игрокам с обычной установкой из Steam.

- раньше клиент игрока сверял с профилем арбитра всю папку игры файл за файлом, и бой открывался только из точной копии папки арбитра. Теперь сверяются сборки игры и Rimlink, список модов, содержимое их игровых файлов и загруженные определения. Расположение файлов, посторонние файлы в папке игры и личные настройки модов больше не мешают;
- профиль арбитра закрепляет четыре сборки вместо полного списка файлов, поэтому арбитр может работать из обычной установки с модами из Workshop;
- мод сам снимает профиль арбитра: запуск с `-rimlinkExecutorCapture=<папка>` (раньше это умел только инструмент разработчика);
- новая команда `rimlink-tools admin guild-capture profile publish` загружает документы профиля и утверждает его одним шагом.

Требования прежние: RimWorld 1.7 и Harmony; серверу и CLI нужен .NET runtime 10.0.14. Обновляйте сервер и клиенты вместе: профили, снятые до 0.10.2, нужно снять заново. Новых миграций нет.

[Подготовка арбитра](https://github.com/Asofwar/rimlink/blob/main/wiki/ru/admins/passive-outposts.md#guild-arbiter) · [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3830084263)

Проверки: клиентский и серверный наборы тестов пройдены. В RimWorld 1.7.5005 на локальном сервере профиль снят в отдельной копии игры и утверждён новой командой, арбитр зарегистрировался и стал доступен, а клиент из установки Steam в другой папке прошёл проверку совместимости с этим профилем. Полный бой с новым форматом профиля не проводился: кампания назначается не раньше чем через 24 часа после объявления.
