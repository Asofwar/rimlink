# Rimlink 0.8.0

На общей карте появились зоны влияния союзов, а сервер может раздавать подготовленный модпак прямо клиенту.

- добровольная публикация колонии как источника влияния гильдии, цвета, легенда и штриховка спорных клеток;
- влияние остаётся видно, когда владелец офлайн; цвет карты не меняет владельца колонии и права нападения;
- отзыв публикации владельцем и административное отключение источника;
- загрузка опубликованного сервером модпака без Steam: проверка полного содержимого, докачка и защита от опасных архивов;
- установка с резервной копией, восстановлением после прерывания и одним перезапуском игры;
- общие настройки модов устанавливаются до перезапуска; повторный вход проверяет результат до начала игровой сессии;
- CLI для подготовки, публикации и снятия пакета. Администратор подтверждает право раздавать его содержимое; Core и DLC не распространяются.

Требования: RimWorld 1.7 и Harmony; серверу и Discord-боту нужен .NET 10. Для GOG сервер должен разрешать парольный вход. Обход проверки модпака администратором сохранён.

Обновляйте сервер и клиенты вместе. Перед запуском новой версии сохраните весь каталог данных: две миграции применяются автоматически. Для строгой проверки файлов обновите запись Rimlink в серверном модпаке из опубликованного клиентского ZIP. Само обновление не публикует чужие моды и не включает парольный вход.

[Влияние гильдий](https://github.com/Asofwar/rimlink/blob/main/docs/guild-influence.md) · [Доставка модпака](https://github.com/Asofwar/rimlink/blob/main/docs/modpack-delivery.md) · [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3830084263)

Проверки отдельных функций включали два реальных клиента, архивирование и восстановление колонии, обновление карты и один настоящий перезапуск после установки модов. Настоящая GOG-копия недоступна: её запуск не проверен. Steam-копия использовалась в изолированном стенде; это не заменяет проверку GOG. Физическое отключение питания, заполнение диска и предельный архив 2 ГиБ не проверялись.
