# Rimlink 0.10.4

Исправления фонового арбитра по итогам ревью и кнопка администратора в панели Rimlink.

- `rimlink-tools arbiter run` больше не завершается при таймауте запроса к серверу и не останавливает из-за него арбитра;
- пока назначена кампания или идёт бой, профиль арбитра не меняется: обновление игры или модпака применяется после них, а арбитр после сбоя возвращается на прежнем профиле;
- если копия игры уже обновлена, а новый профиль опубликовать не удалось, арбитр не запускается на несогласованной копии, попытка повторяется раз в минуту;
- у папки арбитра один владелец: второй `arbiter setup` или `arbiter run` для неё не запустится; `--home` внутри папки игры отклоняется;
- сертификат сервера запоминается при `arbiter setup`; с `--insecure` токен администратора отправляется только серверу с этим сертификатом;
- шаблон карты боя создаётся заново при изменении списка модов; старые папки профилей удаляются;
- сервер без закреплённого `GuildCapture:ApprovedProfileDigest` отклоняет устаревшую проверку связи арбитра, которая сверяла только этот хеш;
- экспорт «География аванпостов» для администратора перенесён с кнопки каравана в панель Rimlink в правом верхнем углу.

Требования прежние: RimWorld 1.7 и Harmony; серверу и CLI нужен .NET runtime 10.0.14. Обновляйте сервер и клиенты вместе. Новых миграций нет.

[Арбитр гильдейских боёв](https://github.com/Asofwar/rimlink/blob/main/wiki/ru/admins/passive-outposts.md#guild-arbiter) · [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3830084263)

Проверки: клиентский и серверный наборы тестов пройдены. В RimWorld 1.7.5005 на локальном сервере `arbiter setup` снял и опубликовал профиль через закреплённый сертификат; второй `arbiter run` и `arbiter setup` для занятой папки отклонены; после имитации прерванного обновления `arbiter run` повторил его и запустил арбитра. Кнопка «География аванпостов» видна администратору в панели Rimlink; её нажатие и сценарии с назначенной кампанией, сменой сертификата и таймаутом сервера в игре не воспроизводились. Полный бой не проводился.
