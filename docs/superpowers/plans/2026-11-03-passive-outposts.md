# Passive Outposts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: `executing-plans` для рекомендованной реализации основной сессией Sol. `subagent-driven-development` допустим только после отдельного выбора пользователя и без изменения закреплённых моделей/единственного итогового review. Steps use checkbox (`- [ ]`) syntax.

**Goal:** реализовать один личный пассивный аванпост без карты с настоящими работниками, offline-добычей до ёмкости склада и доказуемыми custody/recovery переходами.

**Architecture:** server-owned immutable pawn blobs + append-only custody/operation history и проекции в SQLite; точная аналитическая выработка и свой mailbox. Exact snapshots/receipts связывают игру с сервером; отдельный внешний durable anchor ограждает защищённые transitions и coherent restore. География — явным образом подтверждённый экспорт администратора, не серверная симуляция RimWorld.

**Tech Stack:** C# latest, .NET SDK10.0.402 из [global.json](<../../../global.json>), ASP.NET Core/gRPC/protobuf, EF Core SQLite migrations, xUnit; RimWorld1.7/Harmony mod отдельно от solution; EN/RU keyed XML; admin plain ES modules. Версии пакетов задаёт [Directory.Packages.props](<../../../Directory.Packages.props>); новые зависимости без обоснования не добавлять.

**Spec:** [утверждённый контракт](<../specs/2026-11-03-passive-outposts-design.md>), включая §9 external authority. Сохраняется [recovery0.8.1](<../specs/2026-11-03-recovery-correctness-design.md>).

**Status:** спецификация одобрена пользователем; этот план представлен на отдельное рассмотрение и выбор исполнения. Ни один checkbox не означает выполненную проверку. Подготовка документа не разрешает реализацию, коммиты, публикацию или запуск game/server. База main `e666570f809f86ece3b51b5c5f52935c1079cb4f` (`v0.8.1`); перед исполнением проверить актуальность.

## Global Constraints

- Проектирование/план/review — реальная `gpt-6-astra`; исходники, tests, protocols, migrations, scripts — основная `gpt-6.1-sol`. Не подменять модели. Здесь только интерфейсы и assertions, без готовых implementation bodies.
- Один personal outpost/colony;1–4 real adult free ordinary-human colonists;1000 units;500 wallet silver только успешное основание. WoodLog/Steel, rates20/10*S*H; S=(10+clamp(skill,0,20))/20, H=min(Consciousness,Manipulation,Moving) clamp0..1, finite. Plants/Mining+обе work capabilities фиксируются. Adult life stage, не18years.
- Frozen pawn state: no hunger/aging/healing/illness/skill progression, no upkeep. Offline и обычный server downtime считаются до cap; full warehouse не копит backlog. Archive paused; bulk restore не начисляет backup→restore gap. Fraction сохраняется кроме подтверждённых close/switch; при cap F=0.
- Found/assign только с arrived caravan на main-planet accessible land. Wood natural-tree biome; steel без deposit. Остаток каравана mobile colonist либо совершенно пустой; нельзя бросать груз/пешек. One slot/tile includes Prepared. No map/no guild ownership/influence/no other future features.
- Claim/recall бесплатны через own mailbox, без storage fee; last recall closes. Free durable return не блокируется заполненным mailbox; размер каждого payload ограничен. Voluntary close не возвращает500; technical failure не оставляет final charge.
- Additive protocol только новые tags/messages/enum values; capability защищает tagged pawn/resource/outpost metadata от старых клиентов. EF migrations+schema/upgrade tests; не raw schema patch. Client.Core без Verse; все game objects только main thread/MainThread.Post; все user strings keyed EN/RU.
- Scope=world+owner+generation; write epoch, exact immutable snapshot id/raw hash, permanent PawnCustodyId, per-assignment id, boundary и external head имеют разные роли. Не выводить identity из names/thingID/blob hash. Unknown transfer→manual RecoveryRequired, не guessed replay/return.
- Boundary check раньше replay; внутри допустимой boundary actor+kind+request-id+intent replay раньше business guards. Atomic DB effects+head, anchor completion ДО success/events. Snapshot receipt, не ack/tick, определяет локально выданное имущество и count-once wealth.
- Preserve 0.8.1 immutable upload/exact receipts. Outpost rollback barrier узкий, но история закрытого/возвращённого/перепроданного tagged pawn сохраняется. Reset/recreate preflight всех affected owners ДО любого side effect. Не «сбросить» missing history.
- Единственная coherent supported restore procedure: DB+saves+needed archived saves из общего cut, external anchor не восстанавливается старой копией, fresh boundary и controlled canonical download. Никаких обещаний no-loss для arbitrary mixed copies, намеренной правки anchor+DB или сохранения newer-client timeline поверх старого backup.
- Clean-room: no copied mod/game sources. Не читать secrets/.env. Сохранить чужие [AGENTS.md](<../../../AGENTS.md>) и [docs/verification/2026-11-02-modpack-check.md](<../../../docs/verification/2026-11-02-modpack-check.md>); не stash/reset чужой работы. Одна feature branch после согласования исполнения, не переиспользовать чужую worktree.
- Компьютер общий: отдельный тестовый data/save/game/port stand, не закрывать чужие процессы/MCP/IDE. Реальная game acceptance не заменяется unit tests, и наоборот.
- Ни один intermediate task не включает фичу для пользователей. Feature-readiness остаётся закрытым до всего safety graph; нельзя выпускать production без custody/restore/old-client guards.

## Общие типы и контракт владения

Все перечисленные ниже value types вводятся Task1 в новом `src/Rimlink.Protocol/OutpostContracts.cs`; server-only projections живут в Task1 records. Имена в Interfaces — будущие, не заявление о текущих APIs. В wire — protobuf generated types; конверсия явная, не reflection.

| Тип | Обязательное содержание/семантика |
|---|---|
| OutpostScope | world instance string, player long, generation long, write epoch long, restore boundary string |
| SnapshotProof | snapshot-id,32-byte raw SHA256,scope; не compressed-file hash |
| AuthorityHead / AnchorRecord / TransitionIntent | head UUID+digest; anchor format/world/installation/boundary/committed/pending-or-restore; transition id,kind,actor,old/next heads,digest of immutable intent and effects |
| OutpostStartupResult / OutpostRecoveryDecision / LifecycleDecision | startup Ready/RequiresInitialization/Maintenance; recovery/lifecycle Allowed либо typed blocked reason с required exact evidence; «unknown» никогда не true |
| ProductionState / ProductionResult / WorkerRate | Q,F numerator/denominator,profile,checkpoint; new Q/F/checkpoint; two integer skills,finite binary32 capacity values and both work flags |
| ProductionCheckpoint / ClockSample | persisted UTC и process monotonic provenance; current TimeProvider UTC/timestamp/process id; process id не restore authority |
| OutpostRecoveryData | schema version,scope,registry bindings,immutable transition receipts,frontier/cancellation proofs; bounded strict parser |
| OutpostManifestDocument / ManifestPreview / ManifestRevision | full world/fingerprint/surface/tile data + resource valuation catalog; immutable staged id+digest+validation summary; confirmed id/revision/digest |
| OutpostReturnBatch / ResourceParcel / ResourceCatalogSnapshot | stable batch operation+original custody ids+typed resources+valuation revision+source evidence; allowlisted def/count/version; verified local catalog identity |
| CustodyTransferEvidence / CustodyDepartureEvidence | existing transfer/escrow/removal/receipt chain+old/new custodian; departure death/transfer proof or non-authoritative mirror marker |
| OutpostLocalEvidence / OutpostAdminView | immutable local scope+snapshot+outbox artifacts; bounded administrative projections with reasons and referenced evidence IDs, not mutable blobs |
| RegistryObservation / RegistryValidation / WorkerCaptureResult | UUID/reference-token/scope/tombstone/known server custody; typed pass/conflict; frozen worker facts+blob+digest or typed ineligibility |
| CaravanAdmissionFacts / AdmissionDecision / DeliveryDecision | tile/member/current ownership/residual mobility+cargo facts; typed allow/refuse with keyed reason; delivery validation+required capability/defs |
| RestoreInspection / RestoreRequest / RestoreResult | backup digest/complete manifest checks; inspected digest+paths+explicit operator confirmation/mode; typed phase/completion/new authority |
| AuthorityInitialization / RecoveryResolution | explicit init request with proven empty history+paths; immutable expected-head/evidence digests+chosen supported resolution+audit reason |

Минимальные result DTO могут храниться рядом с потребителем, но таблица — единый semantic contract; при перемещении не плодить одноимённые несовместимые типы. CancellationToken передаётся во всех I/O APIs; отмена ожидания клиента не отменяет уже начатое durable решение. Bound values/size validation перечисляются в options+tests, не задаются неограниченными строками.

## Handoff

Рекомендуемый способ после одобрения плана — **Native: основная Sol последовательно по executing-plans**, затем один независимый итоговый Astra review всей ветки. Причина:16 тесно связанных задач, общие exact snapshot/custody/lock contracts; handoff на каждого implementer повышает риск расхождения. Альтернатива — отдельно согласованное разделение независимых частей между разрешёнными Sol-сессиями без per-task review fan-out и без передачи Astra реализации.

Следующее действие родителя: дать пользователю план и выбор способа исполнения. До его ответа не писать код, не запускать tests/build/game, не создавать execution branch, не коммитить документы/изменения. Локальные commits описаны только как будущие шаги после разрешённого исполнения и проверок; merge/push/release требуют отдельной команды.
