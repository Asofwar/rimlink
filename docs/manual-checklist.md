# Ручной чек-лист (то, что автотесты не покрывают)

Отмечать при каждом релизе. Прогон 2026-10-28 (RimWorld 1.7.4990, локальный сервер, два аккаунта на одном
клиенте): отмечено `[x]`; `[ ]` — не проверялось в этом прогоне.

## Сервер

- [x] **Импорт модпака.** `rimlink-tools modpack import --from <Config>/ModsConfig.xml --mods-dir <RimWorld>/Data <RimWorld>/Mods <workshop>/294100 --server https://host:25560 --token <Admin:ApiToken> --insecure`
      (сначала с `--dry-run`): в списке есть все активные моды с версиями, у Workshop-модов заполнен `workshop_id`.
- [x] **Лимит неавторизованных соединений.** Открыть 6 раз `openssl s_client -connect 127.0.0.1:25560 -alpn h2` без данных:
      шестое соединение закрывается сразу, первые пять закрываются через 30 с (`login timeout`).
- [x] **Steam-вход с настоящим билетом.** Нужен Web API key (https://steamcommunity.com/dev/apikey) в `Auth:SteamWebApiKey`.
      Клиент получает билет через `SteamUser.GetAuthSessionTicket` и вызывает `Auth.Login` — ожидается токен сессии.
      Если Steam отвечает `Invalid ticket` для ключа обычного (не издательского) аккаунта — записать это в `docs/server-setup.md`
      как требование и держать `Auth:AllowPassword=true` как запасной путь.
      2026-10-29: ключ обычного аккаунта подходит. `AuthenticateUserTicket` принял билет, в логе сервера
      `Registered Steam account 7656119…3329 (Player3329)` и `Login Player3329`, диалога пароля нет, клиент открыл новую колонию
      (`login plan: NewColony`).
- [x] **Admin CLI против живого сервера.** `rimlink-tools admin online|broadcast|shutdown --server https://127.0.0.1:25560 --token T --insecure`
      отвечает (HTTP/1.1 на основном порту).

## Клиент

- [x] **Загрузка мода.** В `Player.log` есть `[Rimlink] loaded v<ver>, protocol <n>`; в главном меню кнопка «Мультиплеер».
- [x] **Инструменты агента (BridgeTools), 2026-10-29.** Отдельный стенд (копия игры, сервер :25570), два экземпляра через GABS без кликов: `rimlink/connect` (регистрация, пин, неверный пароль → `Failed` после двух вызовов, вход с сейвом → `Loading`), `start_colony` у админа и на залоченном мире, проход страниц `page_action` с `random_site`, «Мультиплеер» через `click_menu_option`, чат в обе стороны, передача серебра, рейд-снимок, живой визит (предложение → принятие → конец), депозит, лот и покупка, визит и `visit_end`, выход в меню с выгрузкой.
- [x] **Список серверов.** Добавить сервер, подключиться, удалить.
- [x] **Пиннинг сертификата.** Первый коннект — диалог с отпечатком; после подтверждения повторный коннект без вопросов.
- [x] **Смена сертификата.** Удалить `tls/server.pfx` на сервере, перезапустить: клиент показывает предупреждение о смене отпечатка.
- [x] **Steam → пароль.** Без `Auth:SteamWebApiKey` сервер отвечает `Steam ticket is not valid`, клиент открывает диалог аккаунта.
- [x] **Регистрация и вход.** «Создать аккаунт» → `Auth.Register`; неверный пароль → красная ошибка и повторный ввод.
- [x] **Создание мира админом.** Страница мира свободна, после генерации в логе `world '<seed>' registered on the server`.
- [x] **Залоченная страница мира.** Второй игрок видит параметры сервера и баннер «Параметры мира заданы сервером …»; карта совпадает.
- [x] **Поселение.** После старта колонии сервер пишет `<player> settled tile <n>`; поселение без сейва (крэш до первого
      сохранения) освобождается при следующем входе.
- [x] **Чужие поселения.** Поселение второго игрока появляется на карте первого (`placed <name>'s settlement on tile <n>`), не дублируется после загрузки сейва.
- [x] **Выход в меню.** «Выйти в главное меню» → сохранение → выгрузка (`Stored save v<n>`) → меню; следующий вход скачивает сейв и загружает игру.
- [x] **Отложенная выгрузка.** Если выгрузка не удалась, при следующем входе сейв уходит на сервер до загрузки игры.
- [x] **Чат и игроки.** Сообщение видно в окне чата; строки истории не дублируются; окно «Игроки» показывает себя.
- [x] **Обрыв сети.** Перезапуск сервера: игра ставится на паузу, «Связь с сервером потеряна», после возврата сервера — «Связь восстановлена», сессия та же.
- [x] **Уведомления сервера.** `admin broadcast` виден в игре; `admin shutdown 90` показывает предупреждение и запускает сохранение с выгрузкой.
- [x] **Модпак-дифф.** Задать модпак на сервере, убрать один мод у клиента: диалог со списком, «Использовать порядок сервера» пишет `ModsConfig.xml` (бэкап `ModsConfig.rimlink-backup.xml`).
- [x] **Вход с другого места.** Второй клиент тем же аккаунтом: первый получает «вход с другого места» и уходит в меню без переподключения.
- [x] **Два клиента онлайн.** Второй экземпляр игры (`RimWorld.exe -savedatafolder=<папка>`): оба видят друг друга в «Игроки», личные сообщения доходят.

## Связи при возвращении (ветка `asofwar/cool-austin-217d7c`, спека `2026-10-29-rimlink-relations-on-return-design.md`)

Лог: `relations recorded for <пешка>: <n>` при уходе, `relations: <пешка> <связь> <вторая> <исход>` при возвращении. Строки загрузки блоба
