# Ручной чек-лист (то, что автотесты не покрывают)

Отмечать при каждом релизе. Прогон 2026-10-28 (RimWorld 1.7.4990, локальный сервер, два аккаунта на одном
клиенте): отмечено `[x]`; `[ ]` — не проверялось в этом прогоне.

## Сервер

- [ ] **Импорт модпака.** `rimlink-tools modpack import --from <Config>/ModsConfig.xml --mods-dir <RimWorld>/Data <RimWorld>/Mods <workshop>/294100 --server https://host:25560 --token <Admin:ApiToken> --insecure`
      (сначала с `--dry-run`): в списке есть все активные моды с версиями, у Workshop-модов заполнен `workshop_id`.
- [ ] **Лимит неавторизованных соединений.** Открыть 6 раз `openssl s_client -connect 127.0.0.1:25560 -alpn h2` без данных:
      шестое соединение закрывается сразу, первые пять закрываются через 30 с (`login timeout`).
- [ ] **Steam-вход с настоящим билетом.** Нужен Web API key (https://steamcommunity.com/dev/apikey) в `Auth:SteamWebApiKey`.
      Клиент получает билет через `SteamUser.GetAuthSessionTicket` и вызывает `Auth.Login` — ожидается токен сессии.
      Если Steam отвечает `Invalid ticket` для ключа обычного (не издательского) аккаунта — записать это в `docs/server-setup.md`
      как требование и держать `Auth:AllowPassword=true` как запасной путь.
- [x] **Admin CLI против живого сервера.** `rimlink-tools admin online|broadcast|shutdown --server https://127.0.0.1:25560 --token T --insecure`
      отвечает (HTTP/1.1 на основном порту).

## Клиент

- [x] **Загрузка мода.** В `Player.log` есть `[Rimlink] loaded v<ver>, protocol <n>`; в главном меню кнопка «Мультиплеер».
- [x] **Список серверов.** Добавить сервер, подключиться, удалить.
- [x] **Пиннинг сертификата.** Первый коннект — диалог с отпечатком; после подтверждения повторный коннект без вопросов.
- [ ] **Смена сертификата.** Удалить `tls/server.pfx` на сервере, перезапустить: клиент показывает предупреждение о смене отпечатка.
- [x] **Steam → пароль.** Без `Auth:SteamWebApiKey` сервер отвечает `Steam ticket is not valid`, клиент открывает диалог аккаунта.
- [x] **Регистрация и вход.** «Создать аккаунт» → `Auth.Register`; неверный пароль → красная ошибка и повторный ввод.
- [x] **Создание мира админом.** Страница мира свободна, после генерации в логе `world '<seed>' registered on the server`.
- [x] **Залоченная страница мира.** Второй игрок видит параметры сервера и баннер «Параметры мира заданы сервером …»; карта совпадает.
- [x] **Поселение.** После старта колонии сервер пишет `<player> settled tile <n>`; поселение без сейва (крэш до первого
      сохранения) освобождается при следующем входе.
- [x] **Чужие поселения.** Поселение второго игрока появляется на карте первого (`placed <name>'s settlement on tile <n>`), не дублируется после загрузки сейва.
- [x] **Выход в меню.** «Выйти в главное меню» → сохранение → выгрузка (`Stored save v<n>`) → меню; следующий вход скачивает сейв и загружает игру.
- [x] **Отложенная выгрузка.** Если выгрузка не удалась, при следующем входе сейв уходит на сервер до загрузки игры.
- [x] **Чат и игроки.** Сообщение видно в окне чата; строки истории не дублируются; окно «Игроки» показывает себя.
- [x] **Обрыв сети.** Перезапуск сервера: игра ставится на паузу, «Связь с сервером потеряна», после возврата сервера — «Связь восстановлена», сессия та же.
- [x] **Уведомления сервера.** `admin broadcast` виден в игре; `admin shutdown 90` показывает предупреждение и запускает сохранение с выгрузкой.
- [ ] **Модпак-дифф.** Задать модпак на сервере, убрать один мод у клиента: диалог со списком, «Использовать порядок сервера» пишет `ModsConfig.xml` (бэкап `ModsConfig.rimlink-backup.xml`).
- [ ] **Вход с другого места.** Второй клиент тем же аккаунтом: первый получает «вход с другого места» и уходит в меню без переподключения.
- [ ] **Два клиента онлайн.** Второй экземпляр игры (`RimWorld.exe -savedatafolder=<папка>`): оба видят друг друга в «Игроки», личные сообщения доходят.

## Экономика (прогон 2026-10-28, две учётки на одном клиенте, dev-режим)

- [x] **Блобы.** Dev-action «Blob round-trip selected thing»: пешка (навыки, здоровье, одежда) и стак предметов возвращаются без потерь; в логе `blob round-trip ok`.
- [x] **Отправка.** Консоль связи → Rimlink → Отправить: вещи уходят с карты, в логе `saving (transfer)` → `Stored save v<n>` → на сервере `Player A sent parcel N to player B`.
- [x] **Лот.** «Мои лоты» → Выставить: `Market/Post 200`, лот виден в «Рынок» другого игрока.
- [x] **Доставка.** Вход получателя: дроп-под, `parcel N dropped`, `Mailbox/Deliver 200`, затем `saving (delivery)`.
- [x] **Старый сейв при входе.** Локальный файл старше последней передачи + флаг: `pending local save refused (save tick … is older than your last transfer …)`, файл сохранён как `*.stale-<дата>.rws`, загружена копия сервера.
- [ ] **Покупка.** «Рынок» → Купить: серебро списано, посылка прилетает, продавцу `LotSold` и зачисление.
- [ ] **Кошелёк.** Внести серебро из-под маяков (нужна колония с серебром и маяком) → баланс; Выдать → дроп-под с серебром.
- [ ] **Пешка.** Отправить колониста и животное: подтверждение, прибытие в капсуле, фракция игрока, имя/навыки сохранены.
- [ ] **Караван.** Сформировать караван, ПКМ по чужому поселению → «Передать игроку …», по прибытии окно с инвентарём каравана, передача; караван остаётся на тайле.
- [ ] **Повторная доставка после крэша.** Убить игру сразу после приземления пода (до автосейва): при следующем входе под прилетает ещё раз, второго дубля нет.
- [ ] **Старый сейв во время игры.** Загрузить старый сейв вручную при активной сессии: сессия завершается; после входа — диалог «сейв старше последней передачи».
- [ ] **Чужой деф.** Проверка дефов выключена, отправить предмет из мода, которого нет у получателя: у получателя сообщение «посылку не удалось распаковать», посылка остаётся в ящике.
- [x] **Заморозка / outbox.** `economy freeze` → Отправить: вещи ушли с карты, сейв выгружен, сообщение «Сервер не ответил
  (trading is paused: test). Передача сохранена…», запись `Send` в `Saves/Rimlink/<server>_<id>/outbox.json`; `unfreeze` →
  выход в меню → вход: `outbox: Send … answered on replay`, `outbox replay: 1 completed`, одна посылка у получателя.
- [x] **Посылка через Get.** Вход: список почты без блобов, `Mailbox/Get` перед дропом, `parcel 2 dropped`, `saving (delivery)`.
- [ ] **Выход в меню сразу после передачи.** Выход в течение 30 с после двух сейвов (передача + доставка): выгрузка при выходе
  не должна упираться в лимит (3 за 30 с); при таймауте выгрузки ставится флаг и файл уходит при следующем входе.
- [ ] **Возврат отклонённой передачи.**

## Рейды и визиты (прогон 2026-10-29, две учётки на одном клиенте, dev-режим, dev-ярлыки «Raid/Visit a player with selected pawns»)

- [x] **Рейд копиями, сразу, с края.** admin → Nova: `Launch 200`, `Queued`; вход Nova: `Announce`, `Get`, `raid 1 landed: 1 raiders (ArrivalEdge)`,
  фракция «Rimlink raiders» создана, письмо, `Land 200`, `saving (raid-landed)`.
- [x] **Исход.** Рейдер убит (dev T: Kill): `raid 1 resolved: dead 1`, `saving (raid-resolved)`, `Report 200`, на сервере `Resolved {dead: 1}`,
  у атакующего `RaidResolved` в «Рейды».
- [x] **Магазин: выставить.** Гизмо «Продаётся…» → цена 5 → выход в меню → `Shop/Publish 200`, `/api/admin/shop/<id>` показывает запись.
- [x] **Визит и покупка.** admin в гостях у Nova: свой сейв выгружен, копия хозяина загружена (хозяйские пешки — дружественная фракция),
  HUD «В гостях у…», гизмо «Купить (5)» → 3 шт. → `Shop/Buy 200` (15 серебра) → «Закончить визит» → своя колония → посылка через
  `Mailbox/Get`, дроп-под, `Deliver 200`, сейв.
- [x] **Списание у хозяина.** Вход Nova: `PendingRemovals` → 3 шт. удалены → `saving (shop-removal)` → `AckRemoval 200` → `Publish 0 things`.
- [x] **Найдено и исправлено в прогоне.** ID пешки/hediff/генов не регенерировались (дубли ID в сейве защитника); игрок без `FirstSaveAt`
  (старые сейвы) считался новичком; список магазина не публиковался при выходе в меню; деф фракции без кривой стоимости; `SetRelationDirect`
  у goodwill-фракции. Сейв Nova с трупом первого рейдера ещё содержит дубли `Gene_128/129` (до починки) — убрать труп или перегенерировать.
- [ ] **Рейд настоящими пешками (Real).** Пешки уходят с карты/каравана, сейв выгружен, выжившие возвращаются посылкой `RaidReturn` с ранами.
- [ ] **Рейд с предупреждением (Warned).** Письмо, отсчёт `land_at_tick`, высадка через день игры защитника.
- [ ] **Рейд капсулами.** Запуск транспортных капсул на поселение игрока → «Напасть (капсулы)» → дроп-поды у цели.
- [ ] **Караван.** «Напасть»/«Посетить» из меню ПКМ по поселению игрока с караваном на тайле.
- [ ] **Перезагрузка защитника во время рейда.** Сейв после высадки, выход, вход: рейд в `ActiveRaids`, исход всё равно отправляется.
- [ ] **Истечение.** `Raids:ExpireRealDays` 0 + перезапуск сервера: `Expired`, пешки Real вернулись. Высадившийся рейд без отчёта
  истекает так же (окно отсчитывается заново от высадки); `/raids cancel <id> --return` возвращает оригиналы пешек атакующему.
- [ ] **Отказ отчёта.** Сервер отверг `Report` (например, `RAID_GONE` после `/raids cancel`): лут вернулся защитнику капсулой
  («Отклонённая передача возвращается капсулой»), отчёт без лута отправлен повторно, если рейд не `RAID_GONE`.
- [ ] **Обрыв визита.** Выход в меню / потеря связи в гостях: билет закрыт (`Visits/End`), файл `Rimlink_visit_<id>` удалён, своя
  колония грузится при следующем входе; без `End` билет перестаёт работать через `Raids:VisitHours`.
- [ ] **Мирный режим.** Галочка в «Рейды»: отказ `PEACEFUL_MODE` в обе стороны, выключение с задержкой.
- [ ] **Лут.** Рейдер убегает с вещами: `Pawn.ExitMap` → `FLED` с грузом, посылка `Loot` в пределах лимита.
- [ ] **Пленный рейдер.** Захват → `CAPTURED`, остаётся у защитника.
- [ ] **Визит при смене модпака хозяина.** Копия не грузится → `Visit.Failed`, своя колония возвращается. Запись в outbox, получатель сброшен админом (`reset`), вход отправителя: сообщение
  «Отклонённая передача возвращается капсулой», под с содержимым, запись удалена.

## Живые сессии (прогон 2026-10-29, два клиента: хозяин admin в полном экране, гость Nova через `-savedatafolder`, dev-ярлыки «Live raid/visit a player with selected pawns», сервер с `Rimlink__Live__ReconnectWaitMinutes=1`)

  `saving (live-snapshot)`, `snapshot v25 announced`; гость: `loading admin's snapshot v25` → `mirror: entered live session 5 … (snapshot v25)`;
  сервер: `player 1 attached as host`, `player 2 attached as guest`, `Live session 5 running`.
