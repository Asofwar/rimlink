# Итоговый обзор и исправления доставки модпака

Один независимый обзор всей реализации: заморожены58 файлов, исходные SHA-256 сверены. Найдены P1×1 и P2×3. Выполнен один проход исправлений с воспроизведением отказов; второго внешнего обзора не было.

| Замечание | Исправление | Подтверждение |
|---|---|---|
| P1: обычный вход создавал install lock в каталоге игры даже без доставки | Recovery без journal/pending завершается без записи; настоящий pending всё ещё блокирует вход | RED на невозможности создать workspace → GREEN; отдельный тест чужого pending-marker |
| P2: после reload download и login применяли разные auth options | Capabilities/access/publication читают те же применённые IOptions.Value, что обычный login; hot reload аутентификации не добавлен | RED на несовпадении AllowPassword/ServerPassword → GREEN; новая политика согласована после нового запуска сервера |
| P2: false полной проверки после restart игнорировался | Результат передаётся до Session.Begin/outbox; обычный вход и автоматический rejoin останавливаются с понятной причиной. Отдельный ручной admin bypass сохранён. Проверка привязана к исходному endpoint | Тест изменения только Textures и policy matrix; настоящий игровой отказ, сохранённые backups, затем успешный ручной повтор без второго restart |
| P2: settings отсутствующего Allowed-мода навсегда оставляли pending | Проверяется целостность полного сохранённого snapshot; соответствие running handles требуется только для активных модов. Неактивный Allowed допустим | RED на необязательном отсутствующем handle → GREEN; изменение его файла всё равно отвергается. Настоящий игровой прогон с двумя snapshot handles и одним отсутствующим модом |
