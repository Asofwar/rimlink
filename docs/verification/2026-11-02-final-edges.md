# Оставшиеся проверки Rimlink 0.7.0 — 2026-11-02

Проверены физический ввод, откат из браузера, ожидание Steam, диагностика и аварийные экономические сценарии.
**Итог не является общим PASS: найден воспроизводимый дефект административного reset — клиент возвращает старый локальный сейв.**
Описание: [reset resurrection](2026-11-02-reset-resurrection.md).

Исходники: `asofwar/next-features`, HEAD `25f6c8a7cff217782c07fa0d2a349efdaf77f116`.
Runtime и существующие тесты в этом продолжении не менялись. `main`, рабочий Docker-сервер, основная установка игры и Workshop не обновлялись.

## Способ проверки

Три настоящих клиента RimWorld 1.7 с модом 0.7.0, RimBridgeServer и companion из одного дерева.
Игры управлялись профильным GABS/RimBridge MCP; физическая G и браузер — только CUA Driver.
Ctrl+V после ограничений доставки CUA выполнил пользователь; поле затем независимо считано через игровой MCP.
Основной частный стенд использовал TLS-порт 25783; разрушительные reset/archive — копию его DataDir на 25786.
Контрольная база `build/game-acceptance/server` не подвергалась reset этих случаев.

Сырые JSON, снимки, assertions и XML находятся в игнорируемом
`build/game-acceptance/evidence/round2/round7/`. Временные сценарии — в `.superpowers/sdd/next-features/`.
Ни ключ Steam, ни Discord token, ни `.env` для этого прогона не читались.

## Уточнение счётчика предметов

Первый assert офлайн-прогона считал только прямые вещи на земле и ошибочно увидел лишний Steel.
Старые серверные версии независимо восстановлены только для чтения: v53 содержал один Steel35954 в закрытой капсуле старого подарка 13.
После нескольких секунд игры он вышел на землю. Счёт по всем глубокосериализованным предметам под maps сохраняется.
`offline-save-audit.json` и `read-only-server-v51.xml` фиксируют исходную причину; это исправление harness, не продукта.

## Завершение и ограничения

Собственные игры, серверы, fault proxy и частный GABS остановлены. Отдельное окно Chrome закрыто, исходное окно пользователя не закрывалось.
Обе SQLite дали quick_check=ok; текущие сохранения основной тестовой базы совпали с Size/Sha256.
Исходные шесть записей пешек хозяина/партнёра найдены ровно по одному разу, включая запланированный труп и участника каравана.
В обеих базах нет открытых аукционов и недоставленных посылок. Балансы игроков 10649 + 1222 + 773 = 12644;
с банком 356 сохранён весь исходный капитал 13000. `final-storage-integrity.json`, `final-process-cleanup.json`.

Живой Discord не запускался: пользователь подтвердил отсутствие настроенного профиля. 122 теста Discord — отдельный автоматический результат.
Подлинность Steam-билета через настоящий Steam Web API в этом продолжении не проверялась.
Не имитировались отключение питания/повреждение SQLite посреди commit, ошибка Scribe на валидном Zstd и все EN/RU long/error layouts.
Составные пункты чеклиста не повышены до PASS по одному покрытому подпункту. Дефект reset остаётся открытым; исправлений или публикации этого продолжения нет.
