- [CI main](https://github.com/Asofwar/rimlink/actions/runs/41433774139) и [CI тега](https://github.com/Asofwar/rimlink/actions/runs/41434778242) завершились успешно, включая тесты и обе Docker-сборки. Отдельные Windows и WSL (два CPU) прогоны: 1490/1490 каждый.
- GitHub digest каждого из пяти assets совпадает с SHA-256 местного релизного архива. Клиентский ZIP: `6618a8490032e39480e0bf8f9d86998d9ade411129cdf380079361240ad99b1d`.
- Образы доступны без входа в аккаунт; для каждого digest `v0.7.0` совпадает с `latest`:
  - `ghcr.io/asofwar/rimlink-server`: `sha256:682dc9f5b72a63ede47844b9f33bc0713134b569abb07d76de073b49d6f4670d`;
  - `ghcr.io/asofwar/rimlink-discord`: `sha256:1f594ee95c434133e7148380836d0cd0e452e7cdc34124b1a82cc01b2ef03fbd`.
- [Workshop item 3830084263](https://steamcommunity.com/sharedfiles/filedetails/?id=3830084263) обновлён через обычный uploader RimWorld из существующего профиля публикации. Новый ManifestID — `6766025992794169724`, размер 3893551 байт; журнал Steam завершает операцию `Upload finished ... : OK`. Steam API подтверждает visibility 0 (Public), banned 0. После обновления страницы временный баннер автопроверки отсутствовал.
- Загружен тот же набор из 31 файла, что находится в клиентском ZIP на GitHub: перед upload каждый установленный файл проверен по SHA-256; дополнительные файлы отсутствуют. Harmony и BridgeTools в ZIP не входят. Отдельная резервная копия прежнего установленного мода сохранена перед заменой.
- Английский и русский текст страницы обновлены до версии 0.7; Steam API подтвердил полное совпадение описания с `docs/workshop/description.bbcode` после нормализации переводов строк. Название, галерея и зависимость Harmony сохранены.

Рабочий Docker-сервер, его каталог данных и серверный модпак в этом выпуске не разворачивались. Закрыты только собственные игровые стенды и игра профиля публикации. Установленная локальная папка `Mods/Rimlink` обновлена до 0.7.0; скачанный кеш подписки Workshop отдельно не объявлялся проверенным (во время проверки оставался 0.6.2).

Непроверенные границы: настоящий Steam Web API, живой Discord, отключение питания и повреждение SQLite во время commit. Игровые результаты исправления reset и сохранение восстановления после обрыва описаны [отдельно](2026-11-02-save-generation.md).
