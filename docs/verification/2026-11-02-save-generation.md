# Исправление восстановления сброшенной колонии

Исправлен сценарий из [исходного отчёта](2026-11-02-reset-resurrection.md). Проверки выполнены на отдельной копии `generation-server`, порт 25786, и отдельном игровом профиле. Рабочий сервер и пользовательские сохранения не сбрасывались.

## Автоматические проверки

- Полный Windows suite: **1490/1490** — 1051 server, 312 client core, 122 Discord, 5 BridgeTools. Команда `dotnet test Rimlink.sln -nologo -v q`, exit 0; локальный журнал `.superpowers/sdd/next-features/save-generation-tests.log`.
- Новые серверные сценарии: старый файл после reset, повторный reset, поток upload через reset, восстановление первого сейва без серверной версии, старый hygiene-архив после reset, recreateworld у игрока без первой серверной версии. Схема мигрирует существующие данные в поколение 0.
- Старый EF-контекст с отслеживаемым Player поколения 0 после reset воспроизвёл ошибочное восстановление архива (RED). Чтение свежего поколения внутри блокировки исправило сценарий (GREEN в полном suite).
- Клиентские проверки: XML с/без поколения, передача исходного поколения, решения LoginPlan, уникальные имена отложенных файлов, сохранение pending при временных отказах.
- Фикстуры обновления с 0.6.2 создают старые данные через SQL старой схемы, затем применяют миграции: они не используют новую модель до появления колонки.
- Мод и dev-компаньон собраны. Существующие предупреждения MSB3277/xUnit/nullable не скрывались.

## Настоящая игра

- Старая колония поколения 0 загрузилась без переписывания данных: карта 131351. Это проверка совместимости с прежними сейвами.
- После reset и ожидания 31 секунды (свободный rate bucket) вход завершился **NewColony**, а не Loading. Старый файл сохранён как `*.reset-*.rws`; на сервере не появилось старой версии. Отложенный XML побайтно совпал с распакованной серверной архивной версией.
- Создана новая колония: её XML содержит поколение 1, сервер принял v1. После искусственного сетевого обрыва локальный pending-сейв загрузился при повторном входе; сервер получил следующую версию, pending очищен.
- После итогового прохода исправлений повторены reset и создание новой колонии: поколение **2**, новая карта **119252**, XML содержит 2, сервер принял v1. Повторён обрыв сети: pending-сейв tick 47 восстановлен как v2, загружена именно новая карта 119252, pending очищен. Это также проверяет `StartedNewGame` на собранном моде.
- Исходные ответы и assertions: локально `build/game-acceptance/evidence/round2/generation/`. Прежняя исходная база и копия с воспроизведённой ошибкой сохранены.

При создании русской колонии мост зарегистрировал ошибку генерации имени в `Verse.Grammar.GrammarResolver` (`tradeAdj_fem`/`tradeNoun_fem`). Сообщение прочитано и подтверждено перед продолжением; создание карты, сохранение и вход завершились. Исправления генератора имён в эту правку не входят.

## Итоговый обзор и границы

Выполнен один итоговый обзор правки и один проход исправлений: свежая проверка поколения restore под блокировкой, актуальный login при создании новой игры после reconnect, сохранение pending до переноса отклонённого файла. Полный suite выше выполнен после этих изменений.

Linux на двух CPU и публичный CI проверяются отдельно перед публикацией; их результат нельзя выводить из Windows suite. Живой Discord не проверялся (профиль не настроен), настоящий Steam Web API и повреждение SQLite/отключение питания во время commit не проверялись. Старый клиент после reset должен обновиться до 0.7.0.
