# Shared world and settlements

Applies to: Rimlink 0.8.1 · RimWorld 1.7 · protocol 1.

## Usage {#usage}

All players use the server planet. Choose an unoccupied tile when creating a colony. Foreign settlements show their owner, presence, last-seen time, colony age and wealth band where available.

Caravans and transport pods offer actions at another settlement: transfer, raid, visit or live, depending on mode, host availability and server policy. Read the action label before confirming: a visit and a real raid are not interchangeable.

The guild overlay is optional and does not replace normal map markers.

## Limits and safety {#limits}

The default is one settlement per player. An offline marker does not mean the map keeps simulating. Peaceful mode disables some actions.
