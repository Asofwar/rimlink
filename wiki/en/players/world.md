# Shared world and settlements

Applies to: Rimlink 0.10.2 · RimWorld 1.7 · protocol 1.

## Usage {#usage}

All players use the server planet. Choose an unoccupied tile when creating a colony. Foreign settlements show their owner, presence, last-seen time, colony age and wealth band where available.

Caravans and transport pods offer actions at another settlement: transfer, raid, visit or live, depending on mode, host availability and server policy. Read the action label before confirming: a visit and a real raid are not interchangeable.

The guild overlay is optional and does not replace normal map markers.

## How do I settle and read another settlement? {#settlement}

Colony creation uses the server's existing planet. Find a free tile, inspect biome/terrain and settle. If another player claimed it concurrently, choose another tile; do not try saving a second settlement under the same account.

A green settlement indicator means its owner is online; gray means offline. Wealth bands 1–5 are not exact wallet balances. Select the object for owner, faction, last activity and colony age. Age is measured in game days; last activity is real time.

Select a caravan and right-click the settlement for actions. Read the complete label: transfer, raid, visit and live raid have different risks. Pods use their own arrival options. Alliance color does not replace those rules.

## What happens after a long absence? {#archive}

The server may archive a young, low-wealth colony after a long absence, around two weeks by default with administrator-controlled conditions. This is not save deletion. Login restores it automatically if the tile remains free.

If occupied, do not overlay an old colony onto the new settlement. An administrator needs a free tile and controlled restoration. The “while you were away” letter summarizes server events; no letter can simply mean no events occurred.

## Limits and safety {#limits}

The default is one settlement per player. An offline marker does not mean the map keeps simulating. Peaceful mode disables some actions.
