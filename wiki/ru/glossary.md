# Словарь

Применимость: Rimlink 0.10.2 · RimWorld 1.7 · протокол 1.

## Как пользоваться {#usage}

| Термин | Значение |
|---|---|
| Канонический сейв | Состояние колонии, принятое сервером |
| Эскроу | Предметы, пешки или серебро, удерживаемые сервером до исхода операции |
| Почта / посылка | Доставка и возврат эскроу получателю |
| Outbox | Локальный журнал неподтверждённых исходящих запросов |
| Live / хозяин / гость | Сессия живой карты с единственным авторитетным хозяином |
| Союз / гильдия | Социальная группа; гильдии используют существующие союзы |
| defName | Технический идентификатор типа предмета, например Steel |
| Scope | Набор прав административного API |
| Pin | Отпечаток доверенного TLS-сертификата |

### Идентификаторы восстановления

- **SaveGeneration / поколение**: линия жизни колонии; reset делает прежние локальные сейвы устаревшими.
- **SaveWriteEpoch / эпоха записи**: право записи в текущую временную линию; rollback меняет эпоху и отсекает старые сессии, не создавая новую колонию.
- **Save version / версия сейва**: номер серверного снимка; не версия программы и не generation/epoch.

## Какие термины нельзя смешивать при восстановлении? {#state-terms}

| Термин | Не путать с | Практическое следствие |
|---|---|---|
| Версия Rimlink | Версия сейва | Обновление мода не выбирает снимок колонии |
| ProtocolVersion | Версия RimWorld | Проверяет сетевой контракт, не наличие DLC |
| SaveGeneration | SaveWriteEpoch | Reset создаёт новую жизнь колонии, rollback меняет право записи старой |
| escrow | Почта | Удерживаемое предложение ещё не доставлено получателю |
| request_id | id сделки | Повтор намерения использует тот же request_id |
| Host | Выделенный сервер | В live host — игра владельца карты, не серверный процесс |
| Tick | Реальные часы | Пауза карты не останавливает срок предложения на сервере |
| Альянс | Coop | Социальная группа не выдаёт управление пешками |

## Ограничения и безопасность {#limits}

Названия конфигурационных ключей, команд, кодов ошибок и defName не переводятся. Копия пешки в визите и реальная пешка рейда имеют разный риск.
