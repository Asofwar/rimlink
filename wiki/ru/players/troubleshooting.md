# Проблемы игрока

Применимость: Rimlink 0.9.0 · RimWorld 1.7 · протокол 1.

## Как пользоваться {#usage}

| Симптом | Что проверить |
|---|---|
| Нет Мультиплеера | Версии игры/Harmony, список модов, вложенные папки |
| Отказ сертификата | Адрес, время системы, подтверждённый pin; не отключать TLS |
| Различия модов | Порядок, версии, hash, настройки; применить пакет с закрытой игрой |
| Вещи не отправляются | Консоль/маяки, доступность предметов, долг, угроза, заморозка |
| Live завис после обрыва | Дождаться переподключения, проверить связь хозяина, запросить снимок |
| Coop занят | Один активный партнёр, хозяин дома онлайн, назначены допустимые пешки |

Сначала сохрани свидетельства ошибки: точное сообщение, время, сервер, действие и id операции. Экспорт диагностики создаёт локальный ZIP; проверь содержимое перед самостоятельной отправкой администратору.

### Получить локальный отчёт

1. Открой **Мультиплеер → Диагностика** в списке серверов или диагностику из игрового оверлея Rimlink. Снимок делается при открытии; закрой и открой окно для обновления.
2. Проверь предпросмотр и нажми **Сохранить локальный ZIP**. Путь показывается до сохранения, имя файла — после. Отчёт находится в `Rimlink/Diagnostics` внутри каталога save-data игры; ZIP содержит diagnostics.json и ограниченный events.log без свободного текста сообщений.
3. Для Windows стандартная папка профиля — `%USERPROFILE%/AppData/LocalLow/Ludeon Studios/RimWorld by Ludeon Studios`; игровой журнал отдельно лежит в `Logs/Player.log`. При собственном -savedatafolder ищи данные там. Отчёт не включает этот журнал; согласуй отдельно безопасную выдержку, если она нужна.

## Диагностика по этапу, а не переустановка всего {#triage}

| Этап | Признак | Безопасная проверка |
|---|---|---|
| Запуск | Нет Multiplayer | Мод включён, Harmony/версия/папка, свежий лог |
| TLS | Изменён отпечаток | Адрес, часы, подтверждение администратора |
| Вход | Неверный пароль/бан | Точный метод и аккаунт, не чужие credentials |
| Сборка | Mismatch | Категория diff, путь конфликтной копии |
| Домашняя карта | Старая/reset-версия | Серверный сейв, generation/epoch, причина отказа |
| Экономика | Unknown response | Исходный запрос, почта, журнал; не новый перевод |
| Live | Ожидание/отставание | Хозяин online дома, состояние потока, fresh snapshot |

В отчёте нужны время с зоной, сервер, версия, действие, точный отказ и id операции. Пароль, Steam-ticket и API-token не нужны. Полный Player.log может раскрывать личные пути и данные других модов.

## Когда остановиться и передать данные администратору? {#escalate}

Остановись при изменённом неподтверждённом pin, отсутствии доказательств replay, повторном отказе загрузки после rollback или внешне изменённых файлах установки. Сохрани локальную папку и диагностический ZIP, не редактируй доказательства для «чистого» лога.

Запиши, воспроизводится ли ошибка после повторного входа и какие шаги уже выполнены. Администратору сначала отправь минимальный отчёт и безопасно отобранные строки [Rimlink]. Полную папку сейвов/журналов передавай только отдельным согласованным способом. Встроенный ZIP сам ничего не загружает в сеть.

## Ограничения и безопасность {#limits}

Диагностика не загружается автоматически и не включает Player.log/произвольные логи. Логи игры могут содержать личные данные: не публикуй целиком. Не удаляй восстановительные журналы и не принимай неизвестные сертификаты.
