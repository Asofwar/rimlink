# Клиент, мод и live

Применимость: Rimlink 0.9.1 · RimWorld 1.7 · протокол 1.

## Как пользоваться {#usage}

Client.Core: все сетевые вызовы async/cancellable; состояние UI в SharedState; неподтверждённые мутации в outbox. Никаких Verse/RimWorld references. Мод касается игровых объектов только на главном потоке: результаты фоновой работы через MainThread.Post. Harmony patches — по одному на метод с пояснением причины.

Пешки/предметы передаются ThingBlobs. При входе в мир с возможными совпадающими id нужны newIds:true и ResetMapIndex перед spawn ранее spawned blob. Ссылки на внешние объекты требуют приведения к миру получателя. Pawn equality по thingIDNumber: нельзя Destroy десериализованную копию, равную живой пешке.

В live зеркало — не самостоятельная симуляция. Coop права на собственных пешек хозяина отличаются от владения привезёнными гостевыми; cleanup не должен возвращать хозяйских пешек почтой.

## Путь UI-намерения и граница главного потока {#client-intent}

UI снимает выбранные данные и создаёт намерение, Core отправляет cancellable запрос и обновляет SharedState. Сетевой callback не должен читать/создавать Verse-объекты; перенос результата в игру выполняется MainThread.Post. Отмена ожидания и отмена уже принятой серверной операции различаются.

Для отправок сохраняются журнал и точный snapshot перед сетевой мутацией. При replay используй исходное намерение, не пересобирай товар по текущему выделению. Для получения сначала зафиксируй карту с доставкой, потом подтверждай. Unit-тест Core не доказывает правильность Scribe/ThingBlobs и построения новой карты.

## Пешки: id, отношения и возврат {#pawn-lifecycle}

Десериализованная пешка может равняться живой по thingIDNumber: Destroy копии способен затронуть настоящую. При входе в другой мир обновляй id и map index, согласуй внешние ссылки на faction/ideo/policies. Для ухода/возвращения используй существующие PawnExit/RelationLedger пути, иначе потеряются взаимные отношения и UI-кеш.

Различай владельца вещи, игрока с правом приказа и writer карты. Coop назначает хозяйских пешек, live-визит переносит гостевых; общий cleanup не должен отправить первых партнёру посылкой. Этот случай требует проверки двумя настоящими клиентами.

## Ограничения и безопасность {#limits}

RimWorld 1.7 использует Waylith/CoreCLR, не Unity; UnityEngine — stub. Исследуй реальный тип игры перед предположениями. Локальная сборка и unit tests не заменяют два реальных клиента для игровых изменений.
