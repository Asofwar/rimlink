# Тестирование и приёмка

Применимость: Rimlink 0.8.1 · RimWorld 1.7 · протокол 1.

## Как пользоваться {#usage}

Сначала воспроизведи сценарий и увидь падающий целевой тест, затем минимальное исправление и повтор. Серверные тесты используют настоящий WebApplicationFactory; client-core тесты общаются с тестовым сервером. Полный набор: dotnet test Rimlink.sln -nologo -v q.

Поток Open вернулся — это ещё не peer attached: утверждай по полученным событиям. Таймауты измеряй Stopwatch, не DateTime.UtcNow. Для timing-изменений повтори набор на Linux/двух CPU при доступности среды.

Игровую логику проверяй двумя изолированными экземплярами host/guest, отдельными savedata и сервером/портом. BridgeTools/RimBridge — только доступный dev-инструмент, не зависимость релиза. Запиши фактически выполненные шаги и результат в manual checklist; сценарий сам по себе не является PASS.

Wiki: test:checks → check:content → check:reference → check:drift -- --base &lt;commit&gt; → build → check:links, затем реальный браузер/поиск/мобильная навигация.

## Ограничения и безопасность {#limits}

Не запускай второй сервер на данных живого сервера и не останавливай чужую игру. Общий Player.log может перезаписываться экземплярами. Не называй незапущенный тест успешным.
