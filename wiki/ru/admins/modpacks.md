# Управление набором модов

Применимость: Rimlink 0.10.3 · RimWorld 1.7 · протокол 1.

## Как пользоваться {#usage}

1. Подготовь проверенный набор в отдельной установке игры. Зафиксируй ModsConfig.xml, порядок, версии и hash.
2. Выполни modpack import --from &lt;ModsConfig.xml&gt; --mods-dir &lt;folders&gt; --dry-run. После проверки добавь --server/--token для отправки требований.
3. modpack defs собирает разрешённые ThingDef/PawnKindDef и имена BiomeDef для манифеста мира аванпостов; пустой список выключает эту проверку. Общие настройки импортируются только для выбранных --mod, загружаемых ниже Rimlink.
4. Для серверной доставки выполни modpack package requirements --output &lt;new-file&gt;, затем package pack --source &lt;redistributable-folders&gt; --requirements &lt;file&gt; --output &lt;new-directory&gt;.
5. Проверь archive.zip и manifest.json, лицензии и настройки. package publish --from &lt;directory&gt; требует --confirm-redistribution; --confirm-public и --confirm-shared-settings подтверждают соответствующее раскрытие. Проверь package status; unpublish снимает публикацию.

Протестируй чистого клиента после изменения коллекции.

## Версия коллекции как отдельный релиз {#modpack-release}

Сначала проверь набор на отдельном клиенте. Import --dry-run показывает будущие требования; фактическую отправку выполняй после ревью. Укажи каталоги Steam/local/Workshop, чтобы версии и хеши соответствовали реально загруженным файлам. Общие настройки импортируй только выбранным модам; они могут содержать персональные пути и секреты.

Requirements и ZIP доставки — разные сущности. После изменения требований старый ZIP может стать несовместимым. Пересобери из разрешённых к распространению исходных папок, проверь manifest/archive и отдельное согласие на настройки. Core/DLC и сама игра не входят в пакет.

## Приёмка новой сборки и откат публикации {#delivery-accept}

На чистом тестовом клиенте проверь полный цикл: diff → скачивание → проверка → согласие → restart → повторный вход. Отдельно проверь существующую конфликтную unmanaged-копию и отказ без перезаписи. Это не разрешение удалять пользовательскую папку Mods.

При ошибке unpublish снимает доступность пакета, но не возвращает автоматически уже установленные клиенты и не отменяет импортированные требования. Сохрани предыдущие requirements, исходный пакет и настройки для согласованного возврата. Полный DataDir backup не заменяет отдельную сохранность исходных модов/лицензий и внешнего каталога доставки.

## Ограничения и безопасность {#limits}

Не упаковывай каталог игры, Core/DLC и секреты модов. Pack требует полный подготовленный набор и новый output. Публикация — отдельное внешнее действие оператора. Изменение требований может сделать прежний опубликованный пакет неактуальным.
